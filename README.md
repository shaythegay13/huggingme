# HuggingMe

A social connection platform where users can browse profiles, manage energy states, and send interaction offers.

## Tech Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **UI Components:** shadcn/ui, Framer Motion
- **State Management:** Zustand, TanStack React Query
- **Backend:** Lovable Cloud (database, auth, storage, serverless functions)

## Features

- User authentication (signup, login, email verification)
- Profile creation & editing (photos, bio, energy state, availability)
- Browse & filter public profiles (search, sort, energy/availability filters)
- Send interaction offers with credits system
- AI-powered matchmaker chat
- Schedule settings per user
